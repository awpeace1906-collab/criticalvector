# The Critical Vector

> The Critical Vector — Medicine. Technology. The Continuum.

A blog at the intersection of emergency medicine, anesthesiology, critical care, and the tools we build to serve patients better. Written by a physician-in-training with a critical care background.

## Sections

- **The Continuum** — Case breakdowns and clinical writing spanning prehospital → ED → OR → ICU
- **Projects** — Tools, apps, and clinical guides (AnesCalc, HTML study guides, etc.)
- **Research** — Paper summaries, case reports, literature reviews
- **From the Flight Deck** — Field essays and personal perspective

## Adding a Post

1. Create an HTML file in the appropriate section folder
2. Use the post template (copy any existing post and update content)
3. Add a link to `index.html` in the recent posts list
4. Push to `main` — GitHub Actions deploys automatically

## Tech

Pure HTML/CSS/JS. No build step, no framework, no dependencies. Works offline-capable when combined with the hosted HTML guides.
