Know Your Data

The data type decides which test you're allowed to use. Get this step wrong and nothing downstream is valid.

TypeSub-typeExampleSummarize with
QualitativeNominal (no order)Blood group, sex, ASA classCounts, proportions, mode
QualitativeOrdinal (ranked)Pain score, ASA I–IV orderMedian, mode
QuantitativeDiscrete (whole)Number of PONV episodesMean/median
QuantitativeContinuousMAP, weight, pHMean ± SD (or median)
02

Centre & Spread

Which average, and how scattered around it?

MeasureUse when
MeanSymmetric, continuous, no outliers
MedianSkewed data or outliers (robust to both)
ModeMost frequent value; the only option for nominal data
SDSpread of the raw data around the mean
SEM = SD / √nPrecision of the mean estimate; shrinks as sample size grows
IQRSpread for skewed data, reported alongside the median
Watch for this

SEM is always smaller than SD, sometimes dramatically so with a large n. Authors occasionally report SEM instead of SD because the error bars look tighter and the result looks more precise than it is. Always check which one a figure is actually showing before you interpret the spread.

03

The Bell Curve

Mean = median = mode, and the 68-95-99.7 rule.

Skewed data changes the plan

If the data isn't shaped like this, don't force it: use the median plus a non-parametric test instead. As a quick tell, right-skew (a long tail to the right) pulls the mean above the median; left-skew pulls the mean below it.

04

P-value & Confidence Interval

The two most misquoted numbers in medicine.

TermWhat it actually means
P-valueIf the null hypothesis were true, the probability of seeing a result this extreme or more. It is NOT the probability that the null hypothesis is true.
α (0.05)The pre-set threshold. p < 0.05 → reject the null.
95% CIA range that, if the study were repeated many times, would contain the true population value 95% of the time.
The most common misread

A tiny p-value can still describe a clinically trivial effect, especially in a huge trial. Always read the effect size and its confidence interval, not just whether "p < 0.05" is printed at the bottom of a table.

06

Which Test?

Match the test to the data. This is the table examiners love most.

ComparisonParametric (normal)Non-parametric (skewed/ordinal)
2 independent groupsUnpaired t-testMann-Whitney U
2 paired / before-afterPaired t-testWilcoxon signed-rank
3+ independent groupsOne-way ANOVAKruskal-Wallis
CorrelationPearson rSpearman rho
2 categorical variables—Chi-square (Fisher's if any expected cell < 5)
The trap examiners are actually testing

With 3 or more groups, run one ANOVA (or Kruskal-Wallis), not a series of pairwise t-tests. Running multiple t-tests inflates the overall false-positive rate: each individual test carries its own 5% risk, and those risks compound across comparisons.

07

The 2×2 Diagnostic Table

Sensitivity, specificity, and the prevalence trap.

MeasureFormulaWhat it means
SensitivityTP / (TP+FN)Detects disease. SnNOUT: high Sn, negative result rules OUT.
SpecificityTN / (TN+FP)Excludes disease. SpPIN: high Sp, positive result rules IN.
PPVTP / (TP+FP)Positive test → truly diseased
NPVTN / (TN+FN)Negative test → truly well
The prevalence trap

Sensitivity and specificity are properties of the test itself and don't change with prevalence. PPV and NPV do: as prevalence rises, PPV rises and NPV falls, even with the exact same test performance. The same troponin assay means something different in a chest-pain unit than it does in a low-risk outpatient screen.

08

Likelihood Ratios, ROC, and Sample Size

The high-value extras that separate reading a paper from actually understanding it.

ConceptKey point
LR+ = Sn / (1−Sp)>10 large/conclusive rule-in; 5–10 moderate
LR− = (1−Sn) / Sp<0.1 large/conclusive rule-out; 0.1–0.2 moderate
Sample size ↑ whenSmaller expected effect, more variability (SD), higher desired power, smaller α
Kappa (κ)Inter-rater agreement beyond chance: 1 = perfect, 0 = chance-level
Why LRs beat PPV/NPV

Likelihood ratios are prevalence-independent, which is exactly what PPV and NPV are not. That makes LRs the right tool for moving from a pre-test probability (your clinical suspicion before the test) to a post-test probability (your suspicion after), regardless of how common the disease is in the population you're standing in.
